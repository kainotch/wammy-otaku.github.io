Troubleshooting

Facing source or app issues? Here's how to fix them.

🔧 App Won't Open / Crashes on Launch

Clear App Data

If the app crashes on launch, try clearing the app data:

  1. Go to your device's Settings → Apps → Wammy
  2. Tap Storage
  3. Tap Clear Data
  4. Reopen Wammy
⚠️ Warning

Clearing data will remove your library, reading progress, and settings. Make sure you have a backup first!

Reinstall the App

If clearing data doesn't help, uninstall and reinstall Wammy from the latest release on GitHub.

📚 Sources Not Loading

Update Extensions

Sources may break when websites change their structure. Try updating your extensions:

  1. Go to Browse → Extensions (or Novel Extensions)
  2. Look for extensions with an Update badge
  3. Tap Update on each one

Clear Source Cache

Sometimes cached data from a source can become corrupted:

  1. Go to Browse → Sources
  2. Long-press the source that isn't working
  3. Select Clear cookies

Check Your Internet Connection

Make sure you have a stable internet connection. Some sources may also be blocked by your ISP — try using a VPN.

📥 Downloads Not Working

Check Storage Permission

Wammy needs storage access to download chapters. Go to Settings → Apps → Wammy → Permissions and make sure storage is allowed.

Free Up Storage Space

If your device is running low on storage, downloads may fail silently. Check your available storage and free up space if needed.

🔄 Tracking Not Syncing

Re-login to Tracker

If your tracker suddenly stops syncing:

  1. Go to More → Settings → Tracking
  2. Log out from the tracker service
  3. Log back in

🆘 Still Need Help?

If none of the above solutions work, reach out to us:

  • Open an issue on GitHub
  • File a bug report on GitHub Issues
💡 Tip

When reporting an issue, include your Wammy version (found in More → About) and a description of the problem with steps to reproduce it.
